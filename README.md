# Bo Li — Personal homepage

Academic homepage with a coastal oil-painting design and an interactive 3D research island.

- Homepage: https://primerl.github.io/
- Research island: https://primerl.github.io/island/

## Local preview

Run `python3 -m http.server 8765` from the repository root, then open http://127.0.0.1:8765/. No build step or API keys are required.

The homepage uses `index.html`, `redesign.css`, `site.js`, and `assets/`. The standalone island lives in `island/`; its README documents controls, materials, and background music. Three.js is vendored with its MIT license.

GitHub Pages publishes this repository's configured deployment branch from its root directory.
